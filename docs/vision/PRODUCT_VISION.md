# Nebulaverse-X Product Vision

Nebulaverse-X is a cross-provider repository security-governance and recovery platform with a capable Git workbench.

The broader founder intent and its maturity labels are preserved in the
[Founder Vision](FOUNDER_VISION.md). Current delivery claims remain governed by
the generated [project state](../current/PROJECT_STATE.md), not by vision prose.

## Position

The product joins repository work, verifiable security posture, human-governed
change, and safe recovery in one visual workspace. Its first controlled hosted
alpha prioritises a dependable GitHub golden path and honest, narrower
GitLab/Gitea subsets over provider parity or feature count.

## Principles

- Server-owned authorization, capability, policy, and evidence truth.
- Fail-closed boundaries for unsupported, stale, malformed, or missing evidence.
- Human preview and approval for consequential actions.
- Deterministic, explainable intelligence; paid AI remains optional.
- Bounded operations, explicit provider and hosting limits, and verified cleanup.
- Tamper-evident history without rewriting past outcomes.
- A five-minute path from provider connection to one evidence-backed action.

## Deliberate non-goals for the first hosted alpha

- Production-scale availability, autoscaling, or a production service.
- Full provider feature parity, Bitbucket, or multi-tenancy.
- Autonomous remediation or complete disaster-recovery orchestration.
- Behavioural machine learning or a required paid-AI dependency.
- A generic frontend redesign or complete framework replacement.
- Customer-controlled evidence storage before Phase 5.
- Claims of complete accessibility certification before the alpha audit passes.
