Inside the orbit

One repository, read honestly

The alpha connects a single sandbox repository and works against the real provider behind it. Nothing here is a mock.

  • Every write is previewed

    A change is rendered as a diff against the provider’s live head before a byte is sent, so you approve the change itself rather than the intention behind it.

  • Blocked work is not lost work

    A policy decides which paths a run may touch. When it refuses one, the work comes back intact with a safe way to land it, instead of on the floor.

  • Capabilities are earned, not declared

    What GitHub, GitLab and Gitea can each do here is established by a live run against that provider. A capability nothing has proved does not get a badge.

  • Signals, not badges

    The overview reads the repository’s own health and names the authority this session is actually talking to, so nothing can claim to be live with no identity behind it.

Before you enter

What this alpha will not do

A controlled alpha is defined by its edges. These are the ones worth knowing before you spend an invitation.

  • Sandbox repositories only Connect a sandbox or test repository containing no real secrets, personal data, production deployments, or irreplaceable source. This is the rule the gate asks you to accept, and it is the one that matters most.
  • Invitations when the gate is enabled When required, an invitation is redeemed once against the terms shown beside it. When entry is open, continue without an invitation.
  • Leaving is part of the product What this browser holds can be cleared from inside the interface, without asking anyone.
