# Central Mutation Gateway Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Route every Nebulaverse-X repository mutation through one immutable, action-bound, repository-scoped and fail-closed server boundary.

**Architecture:** Add a pure gateway module backed by `AsyncLocalStorage`, wrap each mutating Express route with a stable action descriptor, and independently assert the active gateway context at every provider write helper or Git transport. Keep the gateway policy-neutral so Tasks 5+ can add permission and policy decisions at one boundary.

**Tech Stack:** Node.js 22, CommonJS, Express 4, built-in `crypto` and `async_hooks`, existing governance scope normalization, Node `assert` contract tests.

## Global Constraints

- GitHub App authentication remains optional.
- Preserve GitHub PAT/OAuth, GitLab token and Gitea token workflows.
- Preserve Render Free deployment and optional Neon PostgreSQL.
- Never place provider credentials, cookies, authorization headers, file contents or commit messages in mutation descriptors or events.
- Task 4 adds no policy decision, provider permission resolver, governance API or UI.
- Follow test-first red/green/refactor cycles.
